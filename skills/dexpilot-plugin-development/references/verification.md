# 验证与交付证据

按任务风险选择测试，重点覆盖会改变行为的边界；局部文字/样式修改不要求重跑所有设备与发布流程。新建/完整迁移按以下层级推进，环境缺失时记录缺口，不把模拟换个名字当验收。

| 层级 | 核验内容 | 能证明什么 |
| --- | --- | --- |
| 静态契约 | 清单字段/权限/Worker 入口、tag、制品路径、来源策略、依赖 peer | 声明和配置一致 |
| 单元/组件 | 状态选择、未知值、命令终态、生命周期竞态、流解码/ACK/回收 | 给定输入下的程序行为 |
| 独立 registry 构建 | 单仓 checkout、frozen install、类型检查、测试、生产 build/package | 不依赖邻仓源码，打包链路可复现 |
| Desktop 集成 | 隔离开发存储/安装器、协议资源、模块识别与权限 | 指定宿主可解析与加载 |
| Electron 模拟 | 真 iframe、context 切换、未授权请求、Worker、懒加载、卸载/重开 | 沙箱和生命周期实际运行 |
| 真机 | 指定硬件/固件/Adapter、有效状态、帧增长、参数写入与终态 | 真实数据与控制链路 |
| 远端 CI/发布 | 实际 pipeline、tag、产物复用、GET 大小/SHA-256 回读 | 远端交付成功；仍不等于真机 |

## 必须覆盖的失败场景

- 首次握手迟到、快速关闭、订阅/开流结果晚于设备切换；旧请求不会污染新实例。
- 模型或 Worker 加载失败、buffer 耗尽、畸形帧、重复/倒序序号、未知 layout、文本/二进制不匹配。
- 正常/异常帧 ACK 次数，暂停和设备切换后 lease 归还；长时间运行队列和内存有界。
- 命令超时或部分失败时显示未确认；不默认重发标定、重启、录制等有副作用操作。
- 录制/文件保存期间拒绝离开，取消离开后可继续操作；宿主失联时存在可结束的清理流程。
- 本地源码正常可用，同时生产模式拒绝 link、范围依赖、本地模块导入和 dist-dev 混装。
- 合法/非法 tag、tag/manifest 不一致、路径中额外 build-id、同坐标异内容、上传结果不明、GET 摘要不匹配。

对 UI 的验证要观察真实页面状态、控制台和网络/端口证据；状态仅显示「已连接」不能证明收到真实帧。开发预览与生产安装分别操作，隔离测试不得覆盖现有插件存储或终止用户正在使用的 Desktop。

## 建议交付表

| 项目 | 内容 |
| --- | --- |
| 工程 | 位置、入口、保留/迁移的页面、身份映射 |
| 依赖 | npm 精确版本、本地模式命令、来源证明 |
| SDK | states/streams/commands/files、实例选择、生命周期 |
| 构建 | typecheck/test/build/package/dry-run 的实际退出结果 |
| CI | Runner/镜像、非敏感配置、需要的 secret 名称，是否真正运行 |
| 制品 | package ID、版本、平台、文件大小、SHA-256、本地或远端位置 |
| 证据与限制 | 哪些只做了静态/模拟，哪些完成 Desktop/真机/远端回读 |

## 本 Skill 自身的检查

在技能目录运行 `node --test scripts/dependency-mode.test.mjs`，验证依赖切换模板；这些测试使用临时包目录，不会安装依赖或访问网络。复制模板到目标仓库后还应使用该仓库真实的 Vite 进行生产/本地模式构建。

维护 Skill 时检查 frontmatter、相对链接、模板 YAML、文档版本与包 exports。对「新建」和「迁移」各做一次实际场景推演，确认材料足以定位缺失协议、实现脚本而非猜测接口。格式校验不能代替场景检查，模板测试不能代替新插件真机验证。
